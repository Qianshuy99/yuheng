# 玉衡主题助手 v1.0.6: Aurora Nebula

发布日期：2026-08-01

`v1.0.6` 为玉衡主题助手带来新的内置主题 **Aurora Nebula**。它将 AICue 论坛从传统信息流界面重构为一套深空阅读场：高对比排版负责承载讨论，实时星图负责建立空间感，阅读和发帖操作始终保留在明确、可触达的位置。

## 新主题：Aurora Nebula

Aurora Nebula 面向长时间阅读与高频讨论设计。主题不依赖远程图片、字体或第三方脚本，全部视觉效果随 Userscript 一起分发，并能在关闭主题时完整清理。

### 视觉语言

- 深黑基底搭配青绿与珊瑚红的双重强调色，避免单一色相造成的视觉疲劳。
- 首页使用大尺度、分行的标题排版，将站点欢迎语转化为首屏主视觉，同时保留下一段讨论入口。
- 列表改为细线分隔的信息流；标题、作者、标签、回复数和摘要拥有可快速扫描的层级。
- 讨论页维持同一阅读表面，正文、代码块、引用和回复编辑器保持清晰边界，不用装饰性卡片包裹内容。

### 交互体验

- 本地 Canvas 实时渲染星点与连线，根据鼠标位置产生轻微视差；系统减少动态效果偏好和主题的“Live constellation motion”设置都会降低运动。
- 右侧悬浮工具栏使用 Lucide 图标：菜单打开玉衡面板，搜索聚焦站内搜索框，笔形图标触发“发起讨论”。
- 首页底部箭头将视线平滑带到讨论流，右下角密度读数会根据当前页面中的讨论或帖子数量更新。
- “Surface contrast”提供 Deep space 与 Night paper 两种表面层次，设置即时生效，不重新加载页面。

### 响应式策略

- 标题使用固定断点字号，而不是视口比例字号，确保长中文标题在窄屏和缩放环境下稳定换行。
- 侧栏在中小屏折叠为横向导航；发帖按钮保持整行触达区域。
- 移动端工具栏移至底部，操作入口不遮挡正文与编辑器。

## 更新日志

### 新增

- 新增内置主题 `aurora.nebula`，并作为新安装时的默认主题。
- 新增 AICue/Flarum 语义适配、Canvas 星图、页面密度读数和主题级动态/对比度设置。
- 新增首页与讨论页的 Aurora 预览状态，便于视觉回归检查。
- 新增本文档，说明主题设计、交互和升级方式。

### 调整

- 内置主题排序调整为 Aurora Nebula 优先；已有用户的显式主题选择和 XP 旧配置迁移仍会被保留。
- 菜单入口移除表情符号前缀。
- 文档、安装链接、包元数据和 Userscript 版本同步升级至 `1.0.6`。

### 兼容性与质量

- 适用范围：`aicue.top` 与 `*.aicue.top`。
- 无外部资源请求，不依赖远程字体或位图素材。
- 主题卸载时会停止 Canvas 动画、断开 `ResizeObserver` 与 `MutationObserver`、移除事件监听、动态节点和根类名。
- 已通过 `npm run check`，覆盖主题挂载与卸载、AICue SPA 路由适配、导入包校验、门户导航和旧版 XP 回归。

## 升级与使用

1. 安装或更新 `yuheng-1.0.6.user.js`。
2. 访问 AICue 站点，新安装会自动使用 Aurora Nebula。
3. 点击右侧菜单图标或玉衡悬浮控件，打开主题面板。
4. 在“主题设置”中按需要调整动态星图和表面对比度；也可切换回 Windows XP 或已导入主题。
