玉衡主题助手

为网站选择、管理与制作主题。玉衡负责控制与安全边界，Dubhe Core 负责匹配和注入，主题包专注于页面本身。

安装脚本 开始制作主题

01 / 开始使用

安装与更新

  1. 安装脚本管理器在浏览器中安装 Tampermonkey 或 Violentmonkey。
  2. 安装玉衡打开上方“安装脚本”，确认后将 userscript 加入脚本管理器。
  3. 访问支持的网站当前内置 Windows XP Luna 主题适用于 aicue.top。匹配站点时，页面右侧会出现玉衡悬浮球。
  4. 保持更新脚本管理器会按 userscript 的更新地址检查新版；也可以重新打开安装链接手动更新。

02 / 日常操作

在页面上管理主题

选择主题
点击右侧青瓷绿悬浮球，打开面板后为当前站点选择可用主题，或选择“不使用主题”。
调整设置
主题在面板中声明的设置项会显示在主题详情内。修改后会立即应用，或自动重新挂载主题。
导入与导出
面板支持粘贴或拖入 JSON 主题包，也可导出当前主题的纯数据版本，用于分发与二次制作。
快捷开关
Ctrl+Alt+X 可快速启用或关闭 XP 主题；油猴菜单中也提供同类命令。

03 / 导入主题

只导入 CSS 数据包

安全规则

玉衡不会执行导入包内的 JavaScript。导入包只能包含 CSS、变量、匹配规则和设置定义；带脚本字段的包会被拒绝。包含外链资源时，确认页会列出对应域名。

导入步骤

  1. 打开玉衡面板，选择“导入主题”。
  2. 粘贴 JSON，或将 JSON 文件拖入对话框。
  3. 检查名称、适用站点与站外资源提示。
  4. 确认导入后，为当前站点选中该主题。

硬性限制

  • CSS 最大 512 KB，变量总量最大 512 KB。
  • 不允许 @import、javascript:、expression() 等危险构造。
  • 导入主题不能覆盖内置主题的 ID。
  • 仅支持 bool、select、text 三类设置项。

04 / 主题制作

先从纯 CSS 主题开始

可分发主题使用 JSON；它不运行代码，因此最适合颜色、排版、间距、组件外观和背景资源的定制。

1

确定匹配范围

为目标站点写 userscript 风格的 match，例如 *://example.com/*。不要使用与主题无关的宽泛规则。

2

限定 CSS 作用域

主题 ID 中的点会替换为短横线。example.paper 的全部规则都以 html.yh-theme-example-paper 开头。

3

声明可配置内容

将颜色、壁纸等全局值放进 vars，将用户可选偏好放进 settings。

4

导入并回归测试

在面板中导入 JSON，测试启用、关闭、刷新和每一项设置。确认关闭后页面没有样式残留。

最小可导入主题

{
  "id": "example.paper",
  "name": "Paper",
  "version": "1.0.0",
  "author": "your-name",
  "description": "用于 example.com 的纸张风格主题。",
  "match": ["*://example.com/*"],
  "runAt": "start",
  "css": "html.yh-theme-example-paper .App { color: #20332c; }",
  "vars": {
    "--example-accent": "#2f6f61"
  },
  "settings": [
    { "key": "compact", "type": "bool", "label": "紧凑布局", "default": false }
  ]
}

CSS 规则

  • 不得写裸 :root、html、body 或无作用域的页面选择器。
  • 不得修改 #yh-shell 及其子节点，玉衡外壳不属于主题覆盖范围。
  • 优先使用稳定的语义类和 data-* 属性，慎用深层 DOM 选择器与 !important。
  • 图片等内联资源使用 data URI，保证导出的主题可独立工作。

验收清单

  • 在所有声明的匹配站点和窄屏宽度下检查布局。
  • 检查启用、切换、关闭和刷新后的结果。
  • 检查文本、表单、弹窗、导航和固定定位元素不互相遮挡。
  • 检查未匹配站点不注入主题样式或 DOM。

05 / 内置主题开发

需要 DOM 或交互时

仓库内主题可在 src/themes/<theme-name>/ 中使用 mount(ctx) 创建主题专属 DOM。它必须返回卸载函数，清理节点、监听器、计时器、观察器和行内覆盖。

所有 CSS 保持在 theme.css，资源通过构建期模块或 data URI 交付。完成修改后运行以下命令，再将更新后的发布产物一并提交。

npm run check
npm run shots
npm run build
